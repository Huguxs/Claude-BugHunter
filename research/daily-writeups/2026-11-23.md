1. **"Achieving the impossible: XSS in innerHTML without equals"** — Masato Kinugawa, PortSwigger Research, 18 Nov 2026.
   https://portswigger.net/research/achieving-the-impossible-xss-in-innerhtml-without-equals
   Technique: `<selectedcontent>` (mirrors a `<select>`'s selected `<option>` content) clones an SVG `<script>` without the HTML spec's "already started" flag being set on the clone in some browsers (pre-patch Chromium, Safari), so the script executes even though it was inserted via `innerHTML` — and the whole payload needs zero `=` characters, bypassing naive character blocklists.
   Skill: **hunt-xss** (Bypass Techniques).
   Applied: yes — new bypass-technique entry + report_count 174→175.

2. **"Blind trust: stealing credentials through CSP"** — PortSwigger Research, 11 Nov 2026.
   https://portswigger.net/research/blind-trust-stealing-credentials-through-csp
   Technique: pure-HTML-injection credential theft that works even under a CSP that blocks all script execution, by abusing `form-action` (not inherited from `default-src`, often left `'self'` or unset) for a same-origin form submit, then a second-stage `<meta name=referrer content=unsafe-url>` + `<meta http-equiv=refresh>` chain to leak the credential-bearing query string via the `Referer` header on navigation to an attacker server. No JS needed.
   Skill: **hunt-html-injection** (new section), cross-referenced from **hunt-xss** CSP Bypass.
   Applied: yes — new section + report_count 6→7; added a one-line pointer in hunt-xss's existing CSP Bypass list.

3. **"CRLF-Powered Desync Attacks: Beheading HTTP Streams"** — PortSwigger Research, 05 Aug 2026.
   https://portswigger.net/research/crlf-powered-desync-attacks
   Technique: a 4-phase methodology for escalating a plain CRLF/header-injection finding (no classic CL.TE/TE.CL mismatch needed) into a full request desync: locate the injection relative to the upstream Host header, fuzz for 2-3 distinct status codes to confirm backend parsing divergence, find an open-redirect gadget that reflects Host/X-Forwarded-Host, then chain injection+desync+gadget to redirect victims' requests to an attacker domain. Falls back to "blind request tunnelling" for access-control bypass if a full desync isn't achievable.
   Skill: **hunt-http-smuggling** (new subsection).
