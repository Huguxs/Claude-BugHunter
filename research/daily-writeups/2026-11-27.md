   Technique: when injection is limited to `innerHTML` (so a plain `<script>` stays inert) and `=` is filtered, wrapping an `<svg><script>` inside a `<select>`'s first `<option>` next to an empty `<selectedcontent>` makes the browser clone the inert SVG script into the HTML namespace without the engine's "already started" flag — the clone executes. 2. **"Blind trust: stealing credentials through CSP"** — Gareth Heyes, PortSwigger Research, 2026-11-11 (updated 2026-11-16).
   <https://portswigger.net/research/blind-trust-stealing-credentials-through-csp>
   Technique: under a strict `default-src 'none'` CSP, an injected `<form>` with no `action` plus a `<textarea>` carrying a second payload can self-submit (GET) because `form-action` doesn't inherit from `default-src`; the resubmitted value renders on reload and sets `referrer unsafe-url` + a meta-refresh to exfiltrate credentials via the `Referer` header — zero script execution.
   Skill: **hunt-html-injection**. **Applied** — added as a "credential theft under a no-JS CSP" impact bullet; also cross-referenced from hunt-xss's existing CSP-bypass notes conceptually (no direct edit needed there, that section already covers SVG/JSONP CSP bypasses for *script* execution; this is the no-script case).
