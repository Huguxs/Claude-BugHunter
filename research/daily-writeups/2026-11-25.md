## Examined and applied

1. **"Blind trust: stealing credentials through CSP"** — PortSwigger Research, 2026-11-11.
   https://portswigger.net/research/blind-trust-stealing-credentials-through-csp
   Technique: on a page with HTML injection but a CSP that blocks `<script>` outright, `form-action` does not inherit from `default-src`/`script-src`. If `form-action` is absent or `'self'`, an injected self-posting `<form>` can still capture sensitive field values and leak them via the `Referer` header on a subsequent redirect — no script execution needed anywhere in the chain.
   Skill: `hunt-html-injection` (new bullet under Impact, with source link).
   Status: applied.

2. **"Making HTTP header injection critical with one prompt"** — PortSwigger Research, 2026-11-04.
   https://portswigger.net/research/making-http-header-injection-critical-with-one-prompt
   Technique: a plain CRLF injection into any value a front-end/CDN reflects into the request it forwards upstream (not a CL/TE mismatch) can be escalated into the same request-smuggling desync primitive, then chained with a Host-trusting redirect gadget to point another user's response at an attacker domain.
   Skill: `hunt-http-smuggling` (new subsection "CRLF-in-a-reflected-header as a desync primitive", with source link).
   Status: applied.

3. **"Achieving the impossible: XSS in innerHTML without equals"** — PortSwigger Research, 2026-11-18.
   https://portswigger.net/research/achieving-the-impossible-xss-in-innerhtml-without-equals
   Technique: the newer `<select>`/`<selectedcontent>` HTML feature deep-clones an option's children; in some Chromium/WebKit builds an SVG-namespaced `<script>` inserted via `innerHTML` does not get the "already started" flag carried onto its clone, so the clone executes even though direct `innerHTML` script insertion is normally inert. Works in filter contexts where `=`, whitespace, and `/` may all be blocked.
   Skill: `hunt-dom` (new note under Phase 0 sinks, "New-HTML-feature mutation sink", with source link).
   Status: applied.
