1. **"Achieving the impossible: XSS in innerHTML without equals"** — PortSwigger Research, 2026-11-18
   https://portswigger.net/research/achieving-the-impossible-xss-in-innerhtml-without-equals
   Technique: the `<selectedcontent>` element clones the selected `<option>`'s children (cloneNode semantics), which can re-execute a `<script>` that was inert at its original injection point inside an `innerHTML` sink. Wrapping the script in `<svg>` avoids needing `=`/`/` and keeps trailing markup intact; some engines didn't flag the SVG-namespace script as "already started," so the clone fires. Browser/version-dependent.
   Skill: `hunt-xss`. **Applied** — added an "innerHTML sink that strips `=`" section with the gadget, browser caveats, and the DOMPurify-bypass note.

2. **"Blind trust: stealing credentials through CSP"** — PortSwigger Research, 2026-11-11
   https://portswigger.net/research/blind-trust-stealing-credentials-through-csp
   Technique: `form-action` doesn't inherit from `default-src`, so an injected `<form>` can still submit under a strict CSP (`default-src 'none'`). Combined with a second reflected payload that sets a loose referrer policy and a redirect, the victim's own browser leaks their typed credentials via the `Referer` header to an attacker host — no JS execution needed, so it bypasses CSP entirely.
   Skill: `hunt-html-injection`. **Applied** — added a "Form injection beats a strict CSP" section; bumped `report_count` 6→7.

3. **"Making HTTP header injection critical with one prompt"** — PortSwigger Research, 2026-11-04
   https://portswigger.net/research/making-http-header-injection-critical-with-one-prompt
   Technique: escalates a plain CRLF header-injection finding (any user-influenced request component, not just the path) into a front-end/back-end desync by checking header ordering relative to the upstream `Host` header, validating via distinct status codes across fuzzed prefixes, and chaining with a redirect gadget (built from `Host`/`X-Forwarded-Host`/absolute-URL) for a lower-risk proof than response-queue poisoning. Falls back to blind request tunnelling if the desync can't be confirmed.
   Skill: `hunt-http-smuggling`. **Applied** — added an "Escalating a plain CRLF header-injection finding into a desync" section; bumped `report_count` 12→13.
