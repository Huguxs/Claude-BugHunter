1. **"Achieving the impossible: XSS in innerHTML without equals"** — PortSwigger Research, 2026-11-18
   URL: https://portswigger.net/research/achieving-the-impossible-xss-in-innerhtml-without-equals
   Technique: An `innerHTML` sink that strips/forbids the `=` character (blocking all attributes and event handlers) can still be popped using the `<selectedcontent>` element, which clones the currently-selected `<option>`'s children (`cloneNode`-style) into the DOM. 2. **"Blind trust: stealing credentials through CSP"** — PortSwigger Research, 2026-11-11
   URL: https://portswigger.net/research/blind-trust-stealing-credentials-through-csp
   Technique: Even a strict CSP (`default-src 'none'`) leaks credentials from an HTML-injection sink with zero script execution, because `form-action` does not inherit from `default-src` and is usually left unset. Inject a self-posting `<form>` (satisfies `form-action 'self'`) that overlays a fake login prompt, then on the reflected re-render follow with a `<meta http-equiv="refresh">` redirect (CSP doesn't restrict meta-refresh) to an attacker host, exfiltrating captured data via the Referer header. A second variant abuses allow-listed JSONP/outdated-library script hosts as gadgets when `strict-dynamic` is absent.
   Skill: `hunt-xss` — **Applied.** Added to "CSP Bypass" bullets, cross-referencing `hunt-html-injection` since the entry point is a plain HTML injection, not script execution.
